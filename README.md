# Väg 827 koodinäyttäjä

GPS-pohjainen tiemerkintäkoodien näyttö tielle 827 (Porjus - Stora Sjöfallet, Norrbotten).
Selainsovellus, toimii offline asennuksen jälkeen.

Generoitu tiedosto, älä muokkaa täällä. Lähde ja rakennusskriptit:
`digiviivat/Ruotsin digiviivat/` (T-ron Oy, yksityinen).

- Data: `data/road827.json`, rakennettu Trafikverketin frisiktsprotokollasta
  ja NVDB:n tien 827 geometriasta.
- Viivalähde: protokollan `Protokoll`-välilehti, 16 yhtenäistä jaksoa.
- Logiikka ja symbolit: samat kuin BD392-versiossa.
